The hidden linear function: four layers deep

Not a game this time, but a puzzle that pits a shallow quantum circuit against shallow classical ones. You get a grid with some nodes marked S and some links switched on. Hidden in that pattern is a linear function. Find it and you've solved a 2D hidden linear function problem (Bravyi, Gosset & König, 2018). A quantum circuit with just four layers of CZ gates solves it at any size. The paper ran it on up to 105 qubits.

5.1Find the hidden linear function

For a set x of nodes, score q(x) = (number of S nodes in x) + 2 × (number of active links with both ends in x), mod 4. Call x balanced if every node is linked to an even number of nodes in x, counting itself when it is an S node inside x. On balanced sets q is always 0 or 2, and it is linear: q(x) = 2·(number of your chosen nodes in x) mod 4, for one fixed choice of nodes. Tap nodes to make that choice.

5.2Why four layers is remarkable

The circuit is fixed: Hadamard on every qubit, S on every S node, CZ on every active link, then Hadamard and measure. A square grid's links split into four sets of non-touching pairs, so all the CZs fit in four layers at any grid size. Every measurement gives a correct answer, chosen uniformly from all of them.

A classical circuit built from two-input gates can only pull together 2d input bits in d layers. Bravyi, Gosset and König proved that shallow classical circuits fail on large instances. That proof applies only at very large sizes, so the paper compares against a simpler yardstick, log2(number of input bits). It scores the noisy chip by effective depth: 4 divided by the fraction of answers that are correct.
