The GHZ game: N players, one parity

Each of N players gets a secret bit xj, with the promise that the bits add up to an even number. Each answers a bit yj. They win if the answers add up to half the questions' sum, mod 2. Players with no shared entanglement can't do better than ½ + 2−⌈N/2⌉, which falls toward a coin toss as N grows. Players sharing a GHZ state win every time. The paper played it with up to 71 qubits.

4.2Grow a GHZ state on the chip

On a 2D chip each qubit only touches its neighbours. The paper grows the GHZ state outward from one qubit: in each step, every qubit already in the state may entangle one fresh neighbour with a CNOT (H·CZ·H). So N qubits need only about √N steps. Darker rings joined later.

4.3Sweep N up to 71

The paper's experiment: for each N, 20 random games, each played on many random growth patterns with 1000 shots apiece. In their words, the measured win rate "always stays above the classical winning probability", but "the margin of advantage narrows with the number of players".
