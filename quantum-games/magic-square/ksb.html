One system, no fixed answers

Same nine observables, but now there is only one player and one pair of qubits. Measure any row or column of the square, in any order, as often as you like. If each observable had a pre-set value waiting to be read, a simple score could never exceed 4. Quantum mechanics scores 6, whatever state the qubits are in. This is the Kochen–Specker–Bell inequality from the paper.

3.1Try to hide the answers in a table

A context is one row or one column: three observables that can be measured together. The score is

χ = ⟨R1⟩ + ⟨R2⟩ + ⟨R3⟩ − ⟨C1⟩ − ⟨C2⟩ − ⟨C3⟩, where ⟨R1⟩ is the average product of the three values read in row 1. Quantum mechanics forces every row product to be +1 and every column product to be −1, so it scores 6.

3.2Now measure the real thing

Two qubits plus one helper (ancilla) qubit. Tap a context to measure its three observables one after another. Each observable is copied onto the ancilla, which is then read and reset, exactly as in the paper. The qubits are never re-prepared: each measurement acts on whatever the previous ones left behind.

3.3The paper's protocol

Each run measures a random sequence of 180 contexts, with the three measurements inside each context in random order, and the run is repeated. The paper used 1000 runs and found χ = 5.618 ± 0.005, well above the hidden-variable limit of 4. As a sanity check it also asked how often one observable reads the same value twice. When it appears in two consecutive contexts, so only compatible things were measured in between, that should happen every time. When something incompatible came in between, it should happen half the time (supplement Fig. S4).

3.4Calibrating the compensation phase

A hardware wrinkle from the supplement (Sec. 4B, Fig. S5). Each Pauli is copied onto the ancilla's phase, and the ancilla is then read and reset. The reset makes the qubit's frequency jump, which leaves an extra, unknown phase on the ancilla in the next measurement. A phase of π flips every reading, and π/2 makes them coin flips. The fix is a virtual Z rotation before the final Hadamard, tuned to cancel the extra phase. Set the hardware's hidden phase, then sweep the virtual Z the way the experimenters did.
